# tsboi.ai Visibility Showcase

This repository is the public showcase of businesses, people, and content made findable through the [tsboi.ai Visibility Engine](https://tsboi.ai).

**tsboi.ai** is a visibility platform for small businesses everywhere. Its Visibility Engine handles the daily technical work of keeping sites, brands and content indexed and discoverable to search engines, AI-powered search tools, and the crawlers that feed them. One thesis drives everything: *making important things findable.*

## What this repository contains

- [`listings/`](./listings) - one public record per listing, kept current as new listings go live
- Each record links to the listing's live page on tsboi.ai and, where applicable, to the business's own website or social presence

## Why a public showcase on GitHub

Search engines and AI tools draw on open, well-structured, publicly accessible pages. Publishing these records here gives every listing one more authoritative, machine-readable place to be discovered from.

## More information

- Website: [https://tsboi.ai](https://tsboi.ai)
- The Visibility Engine submits client URLs daily to search indexes, the IndexNow protocol, and AI search ecosystems
